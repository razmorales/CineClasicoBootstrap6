# Cine Clásico

Página web con un catálogo de películas clásicas. La práctica consiste en aplicar Bootstrap 6 a una página HTML para organizar su contenido y adaptarlo a diferentes tamaños de pantalla.

## Ver la página

[Ir a Cine Clásico](https://razmorales.github.io/CineClasicoBootstrap6/)

## Características

- Barra de navegación responsiva con menú para pantallas pequeñas.
- Catálogo de seis películas con imágenes y datos generales.
- Tarjetas organizadas en columnas según el tamaño de la pantalla.
- Tema claro u oscuro de acuerdo con la configuración del sistema.

El campo de búsqueda y los botones **Ver ficha** son parte de la interfaz; no tienen una función de búsqueda o consulta implementada.

## Tecnologías

- HTML5
- Bootstrap 6 mediante CDN
- Bootstrap Icons

## Cómo abrir el proyecto

1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador.

La carpeta `img` debe estar junto al archivo `index.html`. Se necesita conexión a internet para cargar Bootstrap y sus iconos desde el CDN.
